NonconvexMetaheuristics.MetaheuristicsAlg — Type
MetaheuristicsAlg(algT)

A gradient-free metaheuristic algorithm from Metaheuristics.jl, exposed through the Nonconvex interface. algT is one of the supported single-objective algorithm types: ECA, DE, PSO, ABC, CGSA, SA, WOA, MCCGA or GA, e.g. MetaheuristicsAlg(ECA).

Most algorithms support bounds and nonlinear inequality and equality constraints (handled via Metaheuristics.jl's penalty aggregation); MCCGA is unconstrained-only. Semidefinite constraints are not supported. Options are set through MetaheuristicsOptions.

NonconvexMetaheuristics.MetaheuristicsOptions — Type
MetaheuristicsOptions(; options=Metaheuristics.Options(), kwargs...)

Options for MetaheuristicsAlg, passed to optimize as options = .... The keyword arguments are forwarded to the wrapped Metaheuristics.jl Options (population size, iterations, tolerances, etc.); see the Metaheuristics.jl options documentation.
